# 生产力Agent with Memory - 开发文档

## 1. 系统概述

**目标**: 构建AI生产力助手,将松散思维转化为可执行任务,并通过记忆实现个性化和长期目标追踪。

**核心能力**:
- 任务分解与精准化
- 跨会话目标追踪
- 工作风格学习
- 进度主动管理

---

## 2. 架构设计

### 2.1 Memory三层架构

| 层级 | 存储内容 | 技术方案 | 用途 |
|------|---------|---------|------|
| Working Memory | 当前会话状态、活跃任务 | LangGraph StateGraph | 单次对话上下文 |
| Episodic Memory | 历史对话、任务片段 | Qdrant向量库 | 语义检索相关历史 |
| Semantic Memory | 用户偏好、风格模式 | PostgreSQL | 结构化知识查询 |

### 2.2 数据模型

**目标记录**:
```
{
  "goal_id": "uuid",
  "user_id": "user123",
  "content": "3个月完成论文",
  "deadline": "2025-03-30",
  "milestones": [...],
  "status": "active",
  "created_at": timestamp
}
```

**任务记录**:
```
{
  "task_id": "uuid",
  "goal_id": "parent_goal_uuid",
  "content": "完成文献综述",
  "estimated_hours": 8,
  "status": "in_progress",
  "completion_rate": 0.4
}
```

**用户偏好**:
```
{
  "user_id": "user123",
  "task_granularity": "2-3小时",
  "communication_style": "简洁",
  "planning_time": "morning",
  "confidence": 0.85,
  "sample_size": 42
}
```

### 2.3 状态机

```
空闲 → 规划 → 执行 → 回顾 → 学习
         ↓       ↓       ↓       ↓
      存目标  追踪进度  生成总结  更新偏好
```

## 5. 关键算法

### 5.1 混合检索

```
相似度得分 = 
  0.7 × 向量余弦相似度 +
  0.2 × 时间衰减因子 +
  0.1 × 显式标签匹配
```

### 5.2 偏好更新

```
新置信度 = 旧置信度 × 0.9 + 新观察 × 0.1
if 样本量 > 20:
    应用该偏好
```

### 5.3 任务分解策略

基于用户历史完成率动态调整粒度:
- <50%: 拆分为1小时任务
- 50-80%: 用户偏好粒度
- >80%: 可适当增大
