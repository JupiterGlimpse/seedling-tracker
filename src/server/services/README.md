# services - 业务逻辑层

> ⚠️ 一旦我所属的文件夹有所变化，请更新我。

## 架构说明
封装核心业务逻辑，不依赖 HTTP 层。
AI 服务调用外部 API，storage 管理数据库操作，scheduler 管理定时任务。

## 文件列表

| 名称 | 地位 | 功能 |
|------|------|------|
| `ai.js` | 核心 | 调用 AI API 分析内容、生成摘要、归类项目 |
| `storage.js` | 核心 | 封装数据库操作（CRUD），提供数据访问接口 |
| `scheduler.js` | 核心 | 定时检查项目，生成提醒任务 |
