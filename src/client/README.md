# client - 专业级前端界面

> ⚠️ 一旦我所属的文件夹有所变化，请更新我。

## 架构说明
高端企业级单页应用，采用原生技术栈实现极致性能。
参考 $50k+ 美术咨询公司专业提案的视觉标准，提供精致的用户体验。
通过 RESTful API 与后端无缝通信，实现智能进展追踪与可视化展示。

## 设计理念
- **配色方案**：深海军蓝 + 琥珀金 + 祖母绿，传达专业、信任、成长
- **视觉层次**：清晰的信息架构，精致的阴影系统，流畅的过渡动画
- **用户体验**：宽松的留白、优雅的交互反馈、完善的无障碍支持
- **响应式设计**：适配桌面、平板、移动端，保持一致的高品质体验

## 文件列表

| 名称 | 地位 | 功能 |
|------|------|------|
| `index.html` | 入口 | 语义化页面结构，包含 ARIA 标签和完善的 meta 信息 |

| `styles.css` | 样式 | 专业级 CSS 设计系统，包含配色、间距、阴影、动画规范 |
